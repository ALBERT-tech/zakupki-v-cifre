# Закупки в цифре

Сайт онлайн-школы **«Закупки в цифре»** — курсы и вебинары для заказчиков и поставщиков в госзакупках: искусственный интеллект в закупках, 44-ФЗ и 223-ФЗ, бюджетное окружение закупок, оценка имущества при торгах.

Владелец — ИП Герасимова Р.Г. Партнёр школы — ЭТП «Сбер А». Эксперт ИИ-направления — Альберт Гизатуллин. Обучение проходит на платформе gc.cifrazakup.ru.

## Структура

- `index.html` — главная-афиша: ближайшее событие, расписание карточками из Google-таблицы, эксперты, как проходит обучение, форма заявки.
- `schedule.js` — чтение таблицы расписания и отрисовка событий (описание колонок и логики в начале файла).
- `course-ai.html` — главный курс «Искусственный интеллект в закупках».
- `styles.css`, `script.js`, `chatbot.js` — дизайн-система, навигация и форма, чат-ассистент.
- `landings/` — блочные файлы для GetCourse (`*-getcourse.html`, UTF-8 с BOM) и их превью; закрыто от индексации.
- `tools/build_main_getcourse.py` — сборка главной для GetCourse из файлов сайта.
- `assets/` — фото экспертов, официальные логотипы партнёра.
- `svedeniya.html`, `documents/` — сведения об образовательной организации (ст. 29 273-ФЗ).
- `backend/` — FastAPI (форма → Telegram, ассистент). **Деплоится на VPS отдельно, в публичный репозиторий не входит.**

Правила работы с репозиторием — в `CLAUDE.md`.
