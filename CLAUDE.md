# Закупки в цифре — сайт онлайн-школы (cifrazakup.ru)

Статический сайт на GitHub Pages (репозиторий ALBERT-tech/zakupki-v-cifre, ветка main → cifrazakup.ru).
Обучение идёт на платформе GetCourse: gc.cifrazakup.ru (лендинги, оплата, личный кабинет `/cms/system/login`).
Владелец школы — ИП Герасимова Р. Г., партнёр школы — ЭТП «Сбер А» (электронная площадка, бывшая Сбербанк-АСТ; не «Сбер» и не «Сбербанк»).

**Внутренний контекст команды, процессы, история решений и открытые задачи — в `docs/CONTEXT.md`.
Папка `docs/` в .gitignore и не публикуется. Читай его первым в начале любой сессии по школе.**

## Структура

- `index.html` — главная-афиша: полоса «Сегодня», карточка «Ближайшее событие» (или событие по utm-метке), расписание карточками с фильтром, эксперты, «Как проходит обучение» + вопросы, форма заявки. Ссылки на стили и скрипты с версией `?v=ГГГГММДД`.
- `schedule.js` — читает Google-таблицу расписания и рисует всё, что связано с событиями. В начале файла описаны колонки, статусы, форматы дат и логика utm.
- `styles.css` — дизайн-система (графит `#14161d`, зелёный `#0e8a52`, Manrope). Старые правила каталога и аккордеона оставлены: их использует `course-ai.html`.
- `script.js` — шапка, мобильное меню, анимации, отправка формы на бэкенд. `chatbot.js` — чат-ассистент.
- `course-ai.html` — страница главного курса «Искусственный интеллект в закупках».
- `landings/` — файлы для GetCourse и их превью (закрыто от индексации в `robots.txt`):
  `ocenka-getcourse.html` (вебинар Кельберг, префикс `kel-`), `ocenka.html` (превью), `main-getcourse.html` (главная для GetCourse, собирается скриптом).
- `tools/build_main_getcourse.py` — собирает `landings/main-getcourse.html` из `index.html`, `styles.css`, `schedule.js`.
- `assets/` — фото экспертов, официальные логотипы партнёра `sber-mark.svg` (знак) и `sber-a-logo.svg` (полный логотип).
- `svedeniya.html` + `documents/` — сведения об образовательной организации по ст. 29 273-ФЗ. `oferta.html`, `privacy.html`.
- `backend/` — FastAPI на VPS (форма → Telegram, ассистент). Не публикуется, деплоится отдельно.
- Связанный репозиторий: ALBERT-tech/budget-procurement-course — лендинг курса Марковой (локально `../sberbank-ast-landing`, файл для GetCourse `getcourse.html`, префикс `bpz-`).

## Правила работы

1. Деплой = push в `main`, GitHub Pages обновляется за 1–2 минуты. После выкладки проверить живой сайт. При изменении css или js поднять версию `?v=…` в `index.html`: Pages кеширует файлы на 10 минут.
2. Концы строк в репозитории LF. Файлы править в бинарном режиме или с `newline=''`; перед коммитом смотреть `git ls-files --eol` и `git diff --stat`. Diff на весь файл означает, что сломались концы строк.
3. Файлы для GetCourse: UTF-8 с BOM, первая строка `<meta charset="utf-8">`, независимые блоки с маркерами `✂`, стили изолированы префиксом или обёрткой `.cz`, все пути абсолютные `https://cifrazakup.ru/…`, нативная форма GetCourse ставится отдельно, чекбокс согласия ссылается на `oferta.html` и `privacy.html`. Инструкция по накату пишется в начале файла.
4. После любой правки главной (`index.html`, `styles.css`, `schedule.js`) пересобрать `python tools/build_main_getcourse.py` и передать файл для переката на GetCourse.
5. Правки проверять локально до коммита: `.claude/launch.json` → `school-site` (http://localhost:8766). Сценарии: прямой заход, `?utm_campaign=budgetenv`, мобильная ширина, отсутствие горизонтального скролла, отсутствие ошибок в консоли.
6. Партнёр везде называется «ЭТП «Сбер А»». Логотипы брать только из `assets/`, не перерисовывать.
7. Записи эфиров доступны 90 дней, формулировка во всех текстах одинаковая.
8. Никаких учётных данных в репозитории и в чате. SSH на VPS только с явного разрешения владельца. Бэкенд в этот репозиторий не коммитится.
9. Коммиты по-русски, описывают смысл изменения. Деливераблы для команды (протоколы, пакеты к встречам) — простой Word в `docs/`, не артефакты.

## Приёмка страницы после наката на GetCourse

Страница открывается без входа, с телефона тоже; блоки и шрифты не слетели; знак партнёра на месте; название, дата, время МСК, спикер, цена совпадают с таблицей; кнопки «Записаться» ведут к форме, тестовая регистрация проходит, письмо приходит с верной ссылкой; чекбокс согласия со ссылками на оферту и политику есть; строка в таблице в статусе «Публикация», событие видно на главной cifrazakup.ru.
